# KotSafe AI collaboration

Before changing project files, read `docs/ai-collab/AI_RULES.md`, `PROJECT.md`, `CURRENT_STATE.md`, and the three newest entries in `WORK_LOG.md` in that folder. Summarize the current state and proposed next steps, then wait for the user's approval before changing code.

Both AI assistants use the same shared folder: `docs/ai-collab/`. After approved work, update its progress and handoff records. See `docs/ai-collab/AI_RULES.md`.
